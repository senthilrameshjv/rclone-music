Privacy policy

Last updated: 22 November 2026

rclone-music is a personal tool used only by its owner, on the owner's own computer, with the owner's own Google account.

What data it accesses

With the owner's permission, it reads, uploads, moves and removes files in the owner's Google Drive. It does this only to keep a Drive copy of the owner's music folder up to date.

How data is used and stored

Files move directly between the owner's computer and the owner's Google Drive. The sign-in token is stored only on the owner's computer. No data is sent to, collected by or stored on any other server, and nothing is shared with, sold to or disclosed to anyone else.

Google user data

rclone-music's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue on GitHub.
